# Week 7: one-command rebuild on an empty Ubuntu server

Date: 2026-11-23. Control node: WSL Ubuntu 26.04, Ansible 15.0.0 (ansible-core 2.22.0).
Target: a brand-new WSL Ubuntu 24.04.5 distro (`wsl --unregister rl-target` first, so nothing was cached).

## Commands

```powershell
wsl --unregister rl-target
powershell -NoProfile -File scripts\new-wsl-target.ps1     # empty distro + SSH + sudo user
```

```bash
cd /mnt/d/Projects/receiptlens/deploy/ansible
ansible-playbook -i inventory.ini site.yml
```

## Result (from-scratch run)

| Step | Time |
|---|---|
| Create the empty target (Ubuntu 24.04 + openssh-server) | 62 s |
| Playbook: Docker Engine, source, secrets, CA + edge certificate, pull and build all images, start, smoke test | 270 s |

```
ok: [rl-target] => {
    "msg": "ReceiptLens is up on https://rl-target:8443/ and OCR read 87.000 đ"
rl-target : ok=27  changed=16  unreachable=0  failed=0  skipped=0  rescued=0  ignored=0
```

The smoke test goes through the public path:
- `/api/healthz` through the edge returns 200, with TLS verified against the target's own CA.
- An SQL injection probe returns 403 from the WAF.
- The synthetic receipt `tests/fixtures/receipt_87000.png` uploads.
- The test waits until the OCR worker stores `status=parsed` and `total_vnd=87000`.

Build time depends mostly on download speed: images plus the PaddlePaddle wheel and OCR models. An earlier run on the same day, which was not from scratch, spent 16 minutes in the build step.

## Re-run (idempotency)

A second run on the same target took **48 s**, with `failed=0` and `changed=2`:
- the source archive is unpacked again;
- `compose up` re-runs the one-shot `migrate` job.

The run kept the existing secrets, CA, certificates and data volumes.

## What stays on the target only

- `/opt/receiptlens/.env` (mode 0600): generated by the playbook; the values are never printed (`no_log`) or saved on the control node.
- `/opt/receiptlens/ca/` (mode 0700): the local CA key, which is not mounted into any container.
- `/opt/receiptlens/edge/certs/edge-key.pem`: mode 0640, group 101 (the nginx user in the edge container).
